# Tribute Page: The Offspring

This project is a tribute page dedicated to the American rock band **The Offspring**, formed in California. It showcases information about their early years, fun facts, and iconic lyrics.

## 🚀 Technologies Used

- **HTML5**: Used for structuring the website's content.
- **CSS3**: Used for styling the layout, typography, and responsive design.

## 📂 Project Structure

Below is the file and folder organization of the project:

```text
.
├── assets/
│   ├── css/
│   │   └── style.css
│   └── img/
│       ├── offspring_1.jpg
│       └── offspring_2.jpeg
├── index.html
└── README.md
```

## 🛠️ How to Run the Project

You can view the project using any of the following methods:

### 1. With Live Server (Recommended)

If you are using **Visual Studio Code**, you can use the **Live Server** extension for a real-time preview:

1. Open the project folder in VS Code.
2. Open the `index.html` file.
3. Click on the **"Go Live"** button in the status bar at the bottom right of the window.
4. The project will automatically open in your default browser at `http://127.0.0.1:5500/`.

### 2. Without Live Server

You can also open the project directly in your browser:

1. Navigate to the project's root folder on your computer.
2. Double-click the `index.html` file.
3. The project will open in your default web browser.
